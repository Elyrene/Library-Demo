图书馆管理系统 — 后端 API

Spring Boot 3 + MyBatis + MySQL · OpenAPI 3.0

通用说明

项说明
Base URLhttp://localhost:8080
认证Session（Cookie）。登录成功后写入 HttpSession，后续请求需携带 Cookie（withCredentials: true）
响应格式{"code": 0, "mes": "ok", "count": 10, "data": {...}}

🔐 认证 /api/auth

POST/api/auth/login

用户登录。根据 role 区分管理员/读者，成功后将用户对象和角色写入 Session。

字段类型必填说明
usernamestring是用户名
passwordstring是密码
rolestring是枚举：admin | reader

请求示例

{ "username": "admin", "password": "admin123", "role": "admin" }

响应 — 成功

{ "code": 0, "mes": "ok" }

响应 — 失败

{ "code": -1, "mes": "账户或者密码错误" }
POST/api/auth/logout

登出。清除 Session 中的用户信息并使 Session 失效。

响应

{ "code": 0, "mes": "ok" }
GET/api/auth/me

获取当前登录用户（不含密码）。未登录时返回失败。

响应 — 管理员

{ "code": 0, "mes": "ok", "data": { "role": "admin", "user": { "id": 1, "username": "admin", "adminType": 1 } } }

响应 — 读者

{ "code": 0, "mes": "ok", "data": { "role": "reader", "user": { "id": 1, "username": "zhangsan", "realName": "张三", "sex": "男", "birthday": "2001-04-01", "address": "江西南昌", "tel": "13767134834", "email": "zhangsan@163.com", "registerDate": "2025-01-15T10:30:00.000+08:00", "readerNumber": "8120116001" } } }

响应 — 未登录

{ "code": -1, "mes": "未登录" }

👤 管理员 /api/admins

GET/api/admins

分页查询管理员列表，支持用户名模糊搜索和类型筛选。password 字段始终为 null。

参数类型必填默认说明
pageNumint否1页码（从 1 开始）
limitint否10每页条数
usernamestring否—用户名（模糊匹配）
adminTypeint否—0=普通, 1=超级管理员

响应

{ "code": 0, "mes": "ok", "count": 3, "data": [ { "id": 1, "username": "admin", "adminType": 1 }, { "id": 2, "username": "qqwer", "adminType": 0 } ] }
GET/api/admins/{id}

根据 ID 查询管理员。password 为 null。

响应 — 成功

{ "code": 0, "mes": "ok", "data": { "id": 1, "username": "admin", "adminType": 1 } }

响应 — 未找到

{ "code": -1, "mes": "管理员不存在" }
POST/api/admins

新增管理员。adminType 不传默认 1（超级管理员）。

字段类型必填说明
usernamestring是用户名（≤20）
passwordstring是密码（≤20）
adminTypeint否0=普通, 1=超级（默认 1）

请求示例

{ "username": "newadmin", "password": "123456", "adminType": 0 }
⚠️ 已知缺陷：用户名重复时返回 "用户名不存在"（应为"已存在"）

响应

{ "code": 0, "mes": "ok" }
PUT/api/admins/{id}/password

修改管理员密码。

⚠️ 已知缺陷：AdminMapper.xml 中未定义 updatePassword SQL，运行时会抛 BindingException（HTTP 500）
字段类型必填说明
passwordstring是新密码

请求示例

{ "password": "newpass123" }
DELETE/api/admins

批量删除管理员。请求体为 ID 数组。

请求示例

[1, 2, 3]

响应 — 空数组

{ "code": -1, "mes": "请选择要删除的管理员" }

📖 读者 /api/readers

GET/api/readers/{id}

根据 ID 查询读者。password 为 null。

响应 — 成功

{ "code": 0, "mes": "ok", "data": { "id": 1, "username": "zhangsan", "realName": "张三", "sex": "男", "birthday": "2001-04-01", "address": "江西南昌", "tel": "13767134834", "email": "zhangsan@163.com", "registerDate": "2025-01-15T10:30:00.000+08:00", "readerNumber": "8120116001" } }

响应 — 未找到

{ "code": -1, "mes": "读者不存在" }
POST/api/readers/register

读者注册。自动生成读者编号（前缀 8120116 + 3 位流水号）。

字段类型必填说明
usernamestring是用户名
passwordstring是密码（6–20 位）
realNamestring是真实姓名
sexstring否性别
birthdaydate否出生日期（YYYY-MM-DD）
addressstring否籍贯
telstring否电话（≤11 位）
emailstring否邮箱（≤15 位）

请求示例

{ "username": "zhangsan", "password": "123456", "realName": "张三", "sex": "男", "birthday": "2001-04-01", "address": "江西南昌", "tel": "13767134834", "email": "zhangsan@163.com" }
⚠️ 用户名重复时返回 "用户名已经存在"。序号超过 999 时编号会溢出为 4 位。

响应

{ "code": 0, "mes": "ok" }

字段类型说明
codeint0=成功, -1=失败
messtring消息
countlong分页总数（仅分页接口）

字段类型说明

passwordstring(20)密码（响应中为 null）

字段类型说明

passwordstring(20)密码（响应中为 null）
realNamestring(20)真实姓名
sexstring(5)性别
birthdayLocalDate出生日期
addressstring(30)籍贯
telstring(11)电话
emailstring(15)邮箱
registerDateDate注册日期
readerNumberstring(20)读者编号（8120116+3位）
